# Визуальная проверка `ua-school-v1-pilot` 0.1.0

Дата рендера: 2026-10-13. Параметры: A4, x-height 4.0 mm, pen width 0.35 mm,
seed 20261013, realism 0. Production SVG отрендерен `rsvg-convert` на белом
фоне и просмотрен целиком и в увеличенном фрагменте.

## Подтверждено

- Все семь frozen words помещаются в printable A4 bounds.
- Разрешённые lowercase пары образуют непрерывные pen-down groups; длинных
  случайных соединительных линий, clipping и выходов за строку не видно.
- `ґ`, `і`, `ї`, `й` сохраняют отдельные верхние marks после основной цепочки.
- `мама` и `Україна` визуально различимы; формы являются центральными
  рукописными траекториями, а не наклонёнными печатными контурами.
- Production SVG не содержит `<text>`, fonts, filled glyph outlines или travel
  moves.

## Требует художественной правки и человеческой оценки

- Повторяющиеся hump-формы `и`, `п`, `т`, `ш` недостаточно различаются в
  плотных словах, особенно `пишу` и `ймовірність`.
- Начальная `У` пока не соединяется с `к`: используется корректный pen-lift
  fallback.
- Для большинства букв есть один universal body для initial/medial/final.
  Отдельные context forms ещё не приняты.
- Только `а`, `е`, `и`, `м`, `о`, `т` имеют два варианта; требование трёх
  human-approved variants не выполнено.
- Визуальная проверка разработчиком не заменяет V-01/V-02 с указанным
  независимым проверяющим и не доказывает качество физического письма.
