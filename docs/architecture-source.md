# Нормативная архитектура

Нормативные документы проекта находятся в корне репозитория. Реализация следует
`README.md`, `ARCHITECTURE.md`, `DATA_MODELS.md`, `MODULE_CONTRACTS.md`,
`IMPLEMENTATION_PLAN.md`, `DECISIONS.md`, `TECH_STACK.md`, `TEST_STRATEGY.md`,
`RESEARCH.md` и `RISKS.md`.

Синхронизированные материалы под `sources/` являются только входными источниками
и не изменяются реализацией.
