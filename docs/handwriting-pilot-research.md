# Исследование источников для украинского рукописного пилота

Проверено 2026-10-13. Цель проверки — найти готовые направленные центральные
траектории украинской связной скорописи и отдельно установить условия
использования кода, шрифтов и данных.

## Результат поиска

Готового набора, который одновременно содержит украинские `ґ`, `є`, `і`, `ї`,
задаёт порядок движения пера, контекстные формы и разрешённые соединения, не
обнаружено. Поэтому ни один внешний glyph set не включён в пилот.

| Источник | Что проверено | Решение |
|---|---|---|
| [utrost/VHS](https://github.com/utrost/VHS) | Захват нескольких вариантов собственных штрихов, JSON central lines, сборка SVG; код AGPL-3.0. Встроенный sample font не является проверенным украинским набором, а права на каждый sample требуют отдельной проверки. | Не копировать код или sample glyphs в MIT-ядро. Использовать как отдельный инструмент будущего захвата собственных образцов. |
| [Google Ink Stroke Modeler](https://github.com/google/ink-stroke-modeler) | Apache-2.0 библиотека сглаживания stylus/touch input с сохранением особенностей движения. Она не содержит украинского алфавита и не решает shaping. | Кандидат для будущего capture adapter, не зависимость генератора этапа I. |
| [Hershey Text в Inkscape](https://inkscape.gitlab.io/inkscape/doxygen-extensions/hershey_8py_source.html) | GPL-2.0+ renderer SVG fonts. Шрифты имеют отдельные лицензии. Hershey-наборы дают engraving strokes, но не подтверждённую украинскую школьную скоропись. | Сохранить как форматный референс. Не импортировать renderer и не считать наличие Cyrillic доказательством украинского покрытия. |
| [Relief SingleLine](https://github.com/isdat-type/Relief-SingleLine) | OFL-1.1 open-path single-line font для CNC. Геометрия шрифтовая sans, не связная школьная скоропись. | Не использовать как стиль; формат полезен для будущего адаптера. |
| [Bad Script](https://github.com/google/fonts/tree/main/ofl/badscript) | Контурный рукописный Cyrillic font под OFL-1.1. Google Fonts хранит исходники и отдельный `OFL.txt`. Контуры не задают центральную траекторию или порядок пера. | Только визуальное сравнение пропорций. Контуры не трассируются и не входят в StylePack. |
| [Marck Script](https://github.com/google/fonts/tree/main/ofl/marckscript) | Контурный OFL-1.1 font; описание Google Fonts прямо указывает на отсутствие соединений между символами. | Только визуальное сравнение; не подходит для connected-stroke backend. |
| [sjvasquez/handwriting-synthesis](https://github.com/sjvasquez/handwriting-synthesis) | Исторический англоязычный Graves-style synthesis. В репозитории нет надёжной лицензии на код и отдельно проверенных прав на weights/style assets. | Не использовать код, веса или данные. |

## Выбранный путь

Пилот строится из специально подготовленных directed centre-line Bézier paths.
Формы не получены наклоном печатного шрифта, skeletonization контуров или
автоматическим jitter. Направление, body stroke, marks, входные и выходные
anchors задаются явно. Геометрия выпускается под MIT вместе с проектом и имеет
собственную provenance-запись.

Это инженерный кандидат `ua-school-v1-pilot`, а не опубликованный
`ua-school-v1`. Его можно загружать существующим runtime только как
`test_only=true`, `production_eligible=false`. Продуктовый gate остаётся закрыт
до V-01/V-02: независимой человеческой проверки читаемости, сравнения со
школьной скорописью и пробного письма на известном оборудовании.

## Границы вывода

Поиск не доказывает, что пригодного набора не существует нигде. Он доказывает,
что проверенные кандидаты не дают готового результата с необходимыми
контрактами и правами. Если позднее появится лицензированный набор центральных
траекторий, его следует подключать через StylePack importer и сравнивать на том
же frozen word/pair corpus, а не заменять им текущий конвейер.
