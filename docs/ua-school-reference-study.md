# Референсы для геометрии украинской школьной скорописи

Проверено 2026-10-13. Цель — определить форму, направление движения и типы
соединений для ревизии `ua-school-v1-pilot/0.2.0`. Ни один внешний glyph,
шрифт, скан или фрагмент защищённого пособия в StylePack не включается.

## Основные источники

1. [МОН, наказ №978 от 04.11.2022](https://mon.gov.ua/npa/pro-utvorennya-robochoyi-grupi-z-rozroblennya-yedinih-zrazkiv-kaligrafichnogo-pisma-bukv-ukrayinskogo-alfavitu-yih-zyednan-ta-cifr)
   учреждает рабочую группу по единым образцам каллиграфического письма букв,
   их соединений и цифр. Страница подтверждает, что форма соединений является
   отдельным предметом нормирования. Она не содержит готового лицензированного
   набора траекторий.
2. [НАПН, «Українська мова. Письмо рукописних малих і великих літер
   алфавіту»](https://lib.iitta.gov.ua/id/eprint/739131/1/%D0%9F%D0%BE%D1%81%D1%96%D0%B1%D0%BD%D0%B8%D0%BA.pdf),
   стр. 77 PDF, показывает рядом печатные `ш`, `п`, `м`, `т` и их рукописные
   формы, затем предлагает дописать элементы и буквы внутри слов. Это важный
   визуальный контрпример текущему пилоту: четыре знака должны распознаваться
   по разным скелетам, а не по числу одинаковых волн.
3. [НАПН, методическая монография о формировании языковой личности младшего
   школьника](https://lib.iitta.gov.ua/id/eprint/712954/1/%D0%BC%D0%BE%D0%BD%D0%BE%D0%B3%D1%80%D0%B0%D1%84%D1%96%D1%8F%20%D0%A4%D0%BE%D1%80%D0%BC%D0%B8.pdf),
   стр. 199 PDF, группирует буквы по движению руки: `п, н, к, т, ...` —
   движение сверху вниз; `і, ї, и, й, ш, щ, у` — сверху вниз с правым
   закруглением; `л, м, я, ґ` — общий начальный подъём снизу вверх. Это даёт
   проверяемое ограничение на направление authored paths.
4. [НАПН, методические рекомендации для 1 класса](https://lib.iitta.gov.ua/id/eprint/714300/1/%D0%9C%D0%A0%201%20%D0%BA%D0%BB%D0%B0%D1%81.pdf),
   стр. 33 PDF, требуют правильных прямых с верхними и нижними закруглениями,
   петель и овалов; естественного безотрывного слияния; верхнего, среднего и
   нижнего типов соединений; ритма и одинакового наклона. Из этого следует,
   что универсальный baseline connector нельзя считать достаточной моделью
   каллиграфического соединения.
5. [НАПН, диагностический инструментарий письменной речи](https://lib.iitta.gov.ua/id/eprint/735314/1/%D0%B4%D1%96%D0%B0%D0%B3%D0%BD%D0%BE%D1%81%D1%82%D0%B8%D0%BA%D0%B0%20%D0%BD%D0%B0%D0%B2%D1%87%D0%B0%D0%BB%D1%8C%D0%BD%D0%B8%D1%85%20%D0%B2%D1%82%D1%80%D0%B0%D1%82_%D0%A3%D0%9C_%D0%BF%D0%B8%D1%81%D0%B5%D0%BC%D0%BD%D0%B5%20%D0%BC%D0%BE%D0%B2%D0%BB%D0%B5%D0%BD%D0%BD%D1%8F.pdf)
   использует сопоставление печатных и рукописных `ш`, `п`, `м`, `т`,
   восстановление элементов и соединение букв как отдельные диагностические
   задания. Источник применён для визуального анализа различимости, без
   извлечения изображений или координат.

Дополнительно сохранены ранее проверенные форматные и лицензионные источники в
[`handwriting-pilot-research.md`](handwriting-pilot-research.md): VHS, Google
Ink Stroke Modeler, Hershey Text, Relief SingleLine, Bad Script и Marck Script.
Ни один из них не даёт готовых направленных украинских школьных траекторий.

## Перевод референсов в authored geometry

Ниже перечислены проектные выводы. Это интерпретация источников для
одноштрихового плоттера, а не цифровая копия страницы прописи.

| Буква | Направление и различительный элемент новой формы |
|---|---|
| `и` | Два наклонных нисходящих штриха сверху вниз; каждый заканчивается правым нижним поворотом. Между ними открытый подъём, а не верхняя арка. |
| `п` | Начальное движение сверху вниз, затем отчётливое верхнее плечо ко второй стойке. Верхняя связь отличает знак от нижних поворотов `и`. |
| `н` | Две стойки с отдельной средней диагональной связкой; она не должна превращаться во вторую полную арку. |
| `т` | Три верхних плеча/арки с нисходящим движением. Начало и вершины должны читаться отдельно от нижних чаш `ш`. |
| `ш` | Три почти прямых нисходящих штриха, соединённых нижними правыми поворотами; вершины не образуют непрерывный ряд одинаковых hump. |
| `щ` | Тот же ритм, что у `ш`, плюс узкий отчётливый нижний штрих после третьей стойки; большой декоративный loop не нужен. |
| `м` | Характерный острый начальный подъём снизу вверх, диагональный спад и отдельное плечо второй части. Это не три равные арки `т`. |
| `ї` | Тело `і`; два раздельных коротких marks над общей серединой, с достаточным интервалом при 3–4 mm. |
| `й` | Тело `и`; отдельная breve должна быть центрирована над телом и не касаться его при минимальном размере. |
| `ґ` | Начальный подъём снизу вверх относится к той же моторной группе, что `л/м/я`; верхний distinguishing mark остаётся отдельным штрихом. |

## Соединения и контекст

- Непрерывность допускается только для элементов «естественного слияния».
  Поэтому pen lift считается правильным результатом, если connector меняет
  характерный элемент или пересекает соседний stroke.
- Вход должен продолжать направление первой части буквы: подъём для `м/ґ`,
  подготовка нисходящего штриха для `п/н/т`, нижний поворот для `и/ш/щ`.
- Upper/middle/lower connection — семантика формы, а не только высота anchors.
  Текущий контракт StylePack имеет classes и позволяет выражать различия
  контекстными variants без изменения движка.
- Конечный terminal можно поднять и завершить отдельно. Final variant с
  `no_join_after=true` честнее universal body, когда продолжение не требуется.
- `У→к` остаётся разрывом: непрерывное соединение не должно создаваться ради
  статистики join rate.

## Пропорции для пилота

- Основное тело: ориентир 650–720 GU при `x_height_gu=1000`.
- Ascenders и marks: до 900–1100 GU; descenders: не ниже −350 GU.
- Проверочный физический размер: `x-height=3.6 mm`, также границы 3.0 и 4.0 mm.
- Наклон создаётся самой геометрией стоек; runtime shear остаётся малой
  вариацией, а не способом превратить печатный знак в рукописный.
- Ширина и расстояние между стойками должны оставлять просвет при pen width
  0.35 mm.

## Права и границы результата

Опубликованные методические страницы используются только как наблюдаемые
референсы формы и движения. Новые Bézier coordinates создаются в проекте
вручную и выпускаются под MIT с provenance `manual_vector`. В StylePack не
включаются сканы, screenshots, font outlines или извлечённые координаты.

Источники достаточны для инженерной ревизии пилота, но не дают права объявлять
формы официальным единым образцом. V-01/V-02 остаются внешними gate: проверка
людьми и физическое письмо известным оборудованием.
