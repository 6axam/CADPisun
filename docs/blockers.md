# Блокирующие задачи

## BLK-STYLE-001 — настоящий `ua-school-v1`

**Блокирует:** завершение I-03 и продуктовый release I-09.  
**Не блокирует:** проверку программного конвейера I-04…I-08 на test-only данных.

В репозитории нет авторских направленных central-line образцов полного набора
UA/RU/EN и нет подписанного протокола визуальной приёмки V-01/V-02. Поэтому
реализация не создаёт автоматически сгенерированный алфавит под именем
`ua-school-v1` и не заявляет качество украинской школьной скорописи.

Для снятия блокера нужны:

1. разрешённые к распространению авторские central-line glyphs и provenance;
2. минимум три принятых варианта каждой уникальной строчной графемы;
3. anchors и pair review для разрешённых соединений;
4. полное покрытие DATA_MODELS §3.3;
5. результаты E-01/E-02 и V-01/V-02 с именем проверявшего.

Для инженерной проверки будет использоваться отдельный
`test-technical-v1`, явно помеченный `test_only=true` и
`production_eligible=false`. Он не является кандидатом на переименование в
`ua-school-v1`.
