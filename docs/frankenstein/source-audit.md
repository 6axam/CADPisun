## Additional primary references

- Qt 6 pointer input will be implemented against the installed PySide6 API and Qt's `QTabletEvent`, `QMouseEvent`, and event-source semantics. Automated tests will construct or translate controlled events rather than rely on a physical tablet.
- Existing CADPisun source and normative project documents remain authoritative for formats, joins, units, safety, validation, and publication.

## Attribution policy

This audit supplies the requested acknowledgment for studied implementations. If later work copies or adapts actual source from a permissive donor, that phase must add the required copyright/license text and identify exact copied files in this document before the code is committed.
